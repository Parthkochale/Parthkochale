<details>
<summary><h2>🐍 Snake Animation Setup (One-time — do this first!)</h2></summary>

### Step 1 — Create the workflow file

In your profile repo (`Parthkochale/Parthkochale`), create the file:
`.github/workflows/snake.yml`

Paste this content:

```yaml
name: Generate Snake Animation

on:
  schedule:
    - cron: "0 */12 * * *"   # Runs every 12 hours
  workflow_dispatch:          # Allows manual trigger

jobs:
  generate:
    runs-on: ubuntu-latest
    timeout-minutes: 10
    steps:
      - name: Generate snake animation (light)
        uses: Platane/snk/svg-only@v3
        with:
          github_user_name: ${{ github.repository_owner }}
          outputs: |
            dist/github-snake.svg
            dist/github-snake-dark.svg?palette=github-dark

      - name: Push to output branch
        uses: crazy-max/ghaction-github-pages@v3.1.0
        with:
          target_branch: output
          build_dir: dist
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
```

### Step 2 — Run the workflow

Go to **Actions tab → "Generate Snake Animation" → Run workflow**

### Step 3 — Done! 🎉

The SVG will appear at `output` branch and display in your README automatically.

</details>
